# Decisions
- [M0] Scaffolded with create-next-app (Next 16.4, React 19.3, Tailwind 4) in a temp dir and copied in, because the project folder was not empty.
- [M0] Disabled Next 16's `cacheComponents`/`partialPrefetching` defaults — the app is client-heavy and local; avoids GET handlers that read env being prerendered at build.
- [M0] @types/node bumped to ^24 to satisfy vitest 5 peer deps.
- [M0] shadcn initialised with the radix base (`radix-nova` style); components restyled to tokens in M1.
- [M0] Model client: openai SDK with maxRetries 0 and our own retry policy (one transient retry after 2s, one 400 → plain-JSON retry), plus a small circuit breaker (3 failures → mock for 60s).
- [M0] .env.local has MODEL_ID=muse-spark-1.3 (newer than plan's 1.1); used as-is.
- [M0] CLI scripts load .env.local with a tiny loader (scripts/load-env.ts) rather than adding dotenv.
- [M1] Theme via next-themes with `attribute="data-theme"` (matches the plan's `[data-theme='dark']` tokens); Tailwind `dark:` variant mapped to the same attribute.
- [M1] shadcn semantic vars (`--primary`, `--border`, …) are defined in terms of the §8 tokens, so restyling is central rather than per component. Added a `danger` button variant for Stop.
- [M1] Added derived tokens `--signal-ink` (amber text readable on paper) and `--flag-shadow` (the single on-screen shadow).
- [M1] Dev indicator disabled so screenshots stay clean.
- [M2] Renderers emit a pure "skeleton" (plain objects, no Excalidraw import) so they're unit-testable in Node; `lib/board/excalidraw.ts` converts on the client with `convertToExcalidrawElements({regenerateIds:false})`.
- [M2] Matrix placement: quadrant by score (4–5 = high half), then nearest free cell in a fixed 3×3 grid per quadrant — non-overlap is guaranteed by construction; overflow spills to the nearest free cell anywhere.
- [M2] Canvas/table rows grow to fit their stickies (row heights computed from item counts), so 12+ items never overlap.
- [M2] Structure elements (axes, block outlines, labels) are `locked` so the facilitator can't nudge the frame by accident; stickies are free.
- [M2] Board text uses Excalidraw's Helvetica (system font) for a clean consulting look; Excalidraw fonts are self-hosted via a postinstall copy to public/excalidraw-assets (offline demo).
- [M2] Library previews use `exportToSvg` rather than ten live Excalidraw canvases (much lighter).
- [M2] Sample script and canned fills live in lib/transcript/sampleScript.ts and lib/frameworks/sampleFills.ts; illustrative fills for the other seven frameworks are clearly marked as preview-only.
- [M3] Accept-on-edit compares a per-sticky signature (x, y, width, text) captured at placement instead of raw element versions — Excalidraw bumps versions itself when it re-measures text after fonts load, which would otherwise auto-accept everything.
- [M3] Acceptance is deferred until the gesture ends (drag/resize/text edit), then applied with CaptureUpdateAction.EVENTUALLY so undo groups it with the user's edit.
- [M3] Toolbar trimmed with CSS (`.ToolIcon:has([data-testid=toolbar-…])`) since Excalidraw 0.18 has no API to hide individual tools; style panel, main menu, library and help are hidden too. Excalidraw's own frame-name label is off (`frameRendering.name=false`) because the frame has an in-canvas title.
- [M3] Standalone `/board?fw=…` route (scratch session) powers "Open board" from /library; the same BoardPanel is embedded in the session console later.
- [M3] `window.__ciacBoardApi` exposes the Excalidraw API for Playwright tests (harmless debug hook).
- [M3] Re-fill merge implemented now (not M9): drops current provisional items, adds new ones nudged clear of existing stickies, skips duplicates of text already on the board, never touches accepted items.
- [M4] Zustand (vanilla store + context) for the console: sources, scheduler and board callbacks read/write state outside React render.
- [M4] Sample and paste share one `ReplaySource` (scripted timeline: interim word-by-word, then sentence finals). The session clock *is* the replay clock, so the 1×/1.5×/3× control also speeds up check pacing and elapsed time.
- [M4] Sample timeline honours the script's [mm:ss] anchors (compressing pace where a paragraph is long) so flags land near the marked points.
- [M4] Paste default speed 2× (≈300 wpm); "Process instantly" emits every final at once (brain scans windows over it in M5).
- [M4] A reloaded live session comes back paused; mic/replay resumes only on click. Replay resumes from the saved position.
- [M4] Start listening calls getUserMedia in the click handler (prompt appears right after the click), then navigates to the console which starts recognition. The start card shows the live level only if mic permission was already granted.
- [M4] Source cleanup is deferred a tick so React StrictMode's simulated unmount doesn't stop a running source.
- [M4] `typecheck` runs `next typegen` first so `PageProps<'/session/[id]'>` route types exist without a build.
